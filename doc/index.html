GoUI / XML UI Guide

GoUI XML 标签使用教程

用 Block 描述界面，用 anchor、pivot、position 和 size 布局；当 size 使用 -1 时，再用 margin 控制边距。Text、Image 和 Button 共享 Block 的基础属性，只增加各自需要的能力。

01 / GoUI XML

开始使用

用户项目自己编写 Go 入口；调用 goui.Open 加载 UI 目录，使用类型化组件绑定事件，再调用 Run 启动。UI 目录包含 config.xml、main.xml 和所有字体、图片与组件资源。

定位一个节点

anchor 选父级上的点，pivot 选自身上的点；两点对齐后，再由 position 偏移，并用 size 定尺寸。

组合与复用

文字和图标都写成独立节点，放进普通 Block 或 Button。需要复用一组节点时，把内容放到组件 XML，再用 component 引用。

最小 config.xml

<config>
  <app name="GoUI Demo" version="1.0.0" />
  <window backend="desktop" display="0"
    width="960" height="640" fullscreen="false"
    decorated="true" resizable="false" />
  <fonts>
    <font name="default" src="fonts/AlibabaPuHuiTi-3-55-Regular.ttf" />
  </fonts>
</config>

将对应的 TTF 文件放入 UI 目录的 fonts/ 中。default 是注册名称，Text 省略 font 时就使用它。app 可省略；应用名作为窗口标题，版本仅保留为应用元数据。window 可省略，默认使用主显示器上的 960×640 桌面窗口。窗口宽高使用设备独立像素；桌面渲染画布会根据显示器缩放比例换算为物理像素。

最小 main.xml

<ui color="#0D1117">
  <text
    id="title"
    anchor="0.5,0"
    pivot="0.5,0"
    position="0,24"
    size="320,40"
    text-color="#F4F7F7"
    font-size="24">GoUI</text>
</ui>

坐标、固定尺寸和字号使用渲染画布像素，父节点左上角为原点，X 向右、Y 向下。桌面模式下，根 ui 的矩形就是窗口客户区；全屏时对应所选显示器。画布会按显示器缩放因子生成物理像素，例如 120% 缩放时，1600×900 个设备独立像素对应 1920×1080 个渲染像素，避免把低分辨率画面再次放大。DRM 后端会直接使用显示设备像素。

Go 入口与按钮事件

package main

import (
  "log"
  goui "github.com/lwy183178053/GoUI"
)

func main() {
  app, err := goui.Open("./ui")
  if err != nil { log.Fatal(err) }

  page := app.Page()
  status, err := page.GetText("status")
  if err != nil { log.Fatal(err) }
  button, err := page.GetButton("run")
  if err != nil { log.Fatal(err) }
  if err := button.OnClick(func(page *goui.Page) error {
    return status.SetText("按钮已执行")
  }); err != nil { log.Fatal(err) }

  if err := app.Run(); err != nil { log.Fatal(err) }
}

按钮点击函数直接在 Go 代码中注册。XML 只负责组件和外观，不用写 action 名称、函数标记或生成步骤。

02 / GoUI XML

UI 目录与文件加载

用户项目自己管理 Go 源码和资源。启动时传给 goui.Open 的目录就是 UI 目录；发布应用时，exe 与该目录一起部署。

MyApp/
  go.mod
  main.go
  ui/
    config.xml
    main.xml
    component/
      display-card.xml
      parts/
        connection.xml
    fonts/
      AlibabaPuHuiTi-3-55-Regular.ttf
      AlibabaPuHuiTi-3-75-SemiBold.ttf
    assets/
      board.png
  • config.xml 和 main.xml 都是必需文件；前者以 <config> 为根，后者以 <ui> 为根。
  • 先读取配置并注册字体，再读取主界面、展开组件并检查最终节点树。没有被引用的组件文件不加载。
  • Go 源码由用户项目自己的 go.mod 编译；框架不生成入口、不扫描源码，也不将 UI 资源打进 exe。
  • 路径使用正斜杠，字体和图片相对 UI 目录；组件路径相对写下引用的 XML 文件。资源路径必须留在指定 UI 目录内。
路径属性相对基准示例
component.src写下该引用的 XML 文件所在目录components/display-card.xml 中的 parts/connection.xml 指向 components/parts/connection.xml。
image.srcUI 目录任何组件中的 assets/board.png 都指向 ui/assets/board.png。
config 中 font.srcUI 目录fonts/AlibabaPuHuiTi-3-55-Regular.ttf 指向 ui/fonts/AlibabaPuHuiTi-3-55-Regular.ttf。
出错时停止加载。缺少必需文件、XML 格式错误、未知标签或属性、重复名称或 ID、无效字体引用都属于加载错误。错误应指出来源文件和位置；组件错误还应显示引用关系。
03 / GoUI XML

config、window 与字体

应用名称、窗口后端和桌面显示设置，以及字体注册表，都在 config.xml 中配置。window 是可选项；fonts 与 default 字体必需。

<config>
  <app name="GoUI Demo" version="1.0.0" />
  <window backend="desktop" display="0"
    width="960" height="640" fullscreen="false" />
  <fonts>
    <font name="default"
      src="fonts/AlibabaPuHuiTi-3-55-Regular.ttf" />
    <font name="semibold"
      src="fonts/AlibabaPuHuiTi-3-75-SemiBold.ttf" />
  </fonts>
</config>
标签 / 属性写法说明
config配置文件根标签整个 UI 目录使用这份配置。
appname、version应用名称用于窗口标题；版本作为应用元数据，不写入 exe 文件属性。
window.backenddesktop 或 drm默认 desktop；当前 drm 仅保留配置识别，启动时会报告尚未实现。
window.display从 0 开始的整数选择桌面显示器；0 是系统主显示器。可通过 goui.Displays() 查询数量、名称和逻辑尺寸。
window.width / height正整数设备独立像素默认 960×640；窗口模式使用该客户区尺寸，全屏模式使用所选显示器报告的尺寸。渲染画布会按缩放比例换算成物理像素。
window.fullscreentrue / false默认 false，桌面后端使用普通窗口。
window.decoratedtrue / false默认 true。设为 false 隐藏系统标题栏和边框；需在 UI 中提供自定义窗口按钮。
window.resizabletrue / false默认 false。设为 true 后允许用户拖动边缘缩放，也可以最大化/还原。
window.min-width / min-height可选正整数设备独立像素窗口模式下的最小宽高；省略时不限制。最小宽高不能超过对应的初始窗口尺寸。
fonts包含多个 font字体注册表，至少登记一个名为 default 的字体。
font.name非空字符串，必需供 text font="名称" 引用；同一注册表中的名称不能重复。
font.srcTTF 文件路径，必需相对于 UI 目录，字体随应用资源提供。

无系统标题栏时，可以在 Go 的 Button 点击事件中调用 app.MinimizeWindow()、app.ToggleMaximizeWindow() 和 app.CloseWindow()。最大化/还原要求配置 resizable="true"。上例中，正文省略 font 即使用 Regular；需要较粗的标题时，显式选择 semibold。需要几种字重，就登记对应的几个文件。

closeButton, err := page.GetButton("window-close")
if err != nil {
    return err
}
if err := closeButton.OnClick(func(*goui.Page) error {
    return app.CloseWindow()
}); err != nil {
    return err
}
<text size="320,40" font="semibold" font-size="24">显示设备</text>

缺少 default、字体重名、文件不存在或无法解析，以及 Text 引用未注册字体时，加载失败。字体直接从 UI 目录读取，目标 Linux 的系统字体不参与查找。首版桌面窗口支持 Windows 和 Linux；DRM/KMS 输出尚未实现。

04 / GoUI XML

通用属性

这些属性由 Block 提供，block、text、image 和 button 都可以使用。每个节点有自己的属性值；visible 控制整棵子树的显示，坐标和尺寸则为子节点提供布局参考。

id

类型：非空字符串 · 默认：无可选节点名称，用于代码查找、状态更新和调试。组件中的 id 在展开后加上组件名前缀，例如 left.title；最终节点树中的 ID 必须全局唯一，重复时报错。根 ui 也可以设置 ID。

visible

类型：true / false · 默认：true设为 false 后，当前节点及整个子树都不绘制，其中的按钮也不参与命中测试。

color

类型：颜色 · 默认：透明设置当前节点自己的矩形填充色，支持 #RRGGBB 和 #RRGGBBAA。所有可视标签都可以使用这个属性，值只作用于当前节点；子节点使用自己的颜色值。Text 的文字颜色由 text-color 设置。根 ui 的 color 是清屏背景色，默认黑色。

radius

类型：非负像素数 · 默认：0设置当前节点填充区域和图片区域的圆角。超过短边一半时按短边一半绘制。圆角只作用于当前节点，子节点可绘制到父矩形外；按钮仍按完整矩形命中。

05 / GoUI XML

anchor

anchor="x,y" 选择父节点矩形中的一个点。两个值都在 0～1 之间，默认 0,0；它决定自身的 pivot 要对齐父节点的什么位置。

anchor="0,0"父节点左上角。
anchor="0.5,0.5"父节点中心。
anchor="1,0"父节点右上角。
anchor="1,1"父节点右下角。

父节点尺寸变化时，这个参考点随之移动。当前轴的 size 为 -1 时，改由该轴边距决定填充位置。

06 / GoUI XML

pivot

pivot="x,y" 选择当前节点自身矩形中的一个点，两个值都在 0～1 之间，默认 0,0。它与父节点上的 anchor 对齐后，再加上 position 偏移。

pivot="0,0" 使用自身左上角，pivot="0.5,0.5" 使用自身中心，pivot="1,1" 使用自身右下角。锚点和轴心只决定对齐方式，尺寸由 size 决定。

把自身中心对齐到父节点中心

<block size="800,400">
  <block anchor="0.5,0.5" pivot="0.5,0.5"
    position="0,0" size="240,80" color="#17212B" />
</block>
parentAnchor = parentRect.origin + parentRect.size × anchor selfOrigin = parentAnchor + position − selfRect.size × pivot

这里的乘法按 X、Y 分别计算。计算结果可以带小数，最终如何对应实际像素见“小数坐标与像素取整”。

07 / GoUI XML

position

position="x,y" 是父级 anchor 与自身 pivot 对齐后的整数像素偏移，默认 0,0。正值向右、向下移动，负值向左、向上移动。

给状态卡片留出偏移

<block
  id="status-card"
  anchor="0,0"
  pivot="0,0"
  position="24,96"
  size="420,180"
  color="#17212B"
  radius="12" />

这里的 position="24,96" 表示卡片左上角距离父组件左上角 24、96 像素。若把 pivot 改成 0.5,0.5，同一个偏移就会作用在卡片中心。

08 / GoUI XML

size

size="width,height" 必须填写两个整数像素值。非负整数表示固定尺寸，-1 表示该方向填充父节点；宽、高分别独立判断，小于 -1 的值无效。

写法结果适用场景
size="240,80"宽 240，高 80固定按钮、标题、图标区域。
size="-1,48"宽填充，高 48横向顶栏、状态条。
size="320,-1"宽 320，高填充侧栏、纵向面板。
size="-1,-1"宽高都填充内容根 Block 或全尺寸背景。

只填充一个方向

<block
  anchor="0,0"
  pivot="0,0"
  position="0,18"
  size="-1,48"
  margin="24,80,24,80"
  color="#23303A" />

这里宽度为 -1，所以只使用左、右边距 24；上、下边距 80 被忽略。高度固定为 48，其 Y 位置仍由 anchor、pivot 和 position 决定。

09 / GoUI XML

margin 边距

margin 按 left,top,right,bottom 的顺序填写四个非负整数像素值，默认是 0,0,0,0。它只作用于 size 中值为 -1 的方向。

size生效的 margin 值忽略的 margin 值
"-1,48"left、righttop、bottom
"320,-1"top、bottomleft、right
"-1,-1"left、top、right、bottom无
"320,48"无left、top、right、bottom

填充方向由 margin 决定，该方向的 anchor、pivot、position 不生效；固定尺寸方向仍按这三个属性定位。左右或上下边距总和超过父尺寸时，该方向尺寸按 0 处理。

10 / GoUI XML

ui 根标签

ui 是 main.xml 的唯一根节点。它的矩形自动覆盖当前渲染目标，直接子节点以这块区域作为父级坐标空间。

属性类型 / 默认值说明
color颜色，默认 #000000渲染背景和清屏颜色，支持 #RRGGBB、#RRGGBBAA。
id非空字符串，可选给根节点命名，最终 ID 全局唯一。
 
<ui id="preview-root" color="#0D1117">
  <block size="-1,-1" margin="24,24,24,24" />
</ui>

ui 的尺寸来自渲染目标，子节点用锚点或填充规则适配尺寸变化。字体等运行配置统一放在 config.xml 中。

11 / GoUI XML

block 标签

block 是最基础的可视节点，也是所有控件的共同基础。它可以有填充色、子节点和自己的布局矩形，但不会自动排列子节点。控件复用 Block 已有的布局、颜色和圆角属性，只增加自身需要的功能。

最小写法

<block
  id="panel"
  anchor="0.5,0.5"
  pivot="0.5,0.5"
  position="0,0"
  size="480,260"
  color="#17212B"
  radius="12" />
idvisibleanchorpivotpositionsizemargincolorradius
布局属性默认 / 要求说明
anchor0,0省略时使用父组件左上角。
pivot0,0省略时使用当前 Block 左上角。
position0,0省略时两个参考点重合。
size必需每个可视子节点都必须给出宽高；只有 ui 根节点自动占满渲染目标。
margin0,0,0,0顺序为左、上、右、下；宽为 -1 时只读左右，高为 -1 时只读上下。

Block 的子节点坐标相对于该 Block 的左上角。父 Block 只负责提供坐标空间和绘制顺序，不会因为子节点数量改变自己的大小。

Block 的 Go 类型还提供 MoveTo、RotateTo 和 ScaleTo。Text、Image、Button 都嵌入 Block，因此这些组件也能直接使用动画方法。MoveTo 改变 position；size=-1 的轴始终按边距填充，不参与位移动画。

不要把 block 当成自动布局容器。如果两个子节点要上下排列，就直接给它们不同的 position；如果要横向排列，也直接写各自的 X 偏移。
12 / GoUI XML

text 标签

text 用节点内容显示文字，共享 Block 的布局、填充色和圆角属性，并提供字体、文字颜色、对齐和自动换行。

属性类型 / 默认值说明
font已注册字体名，默认 default引用 config.xml 中的 font.name，例如 semibold。
font-size像素，默认 16文字大小。
text-color颜色，默认 #F4F7F7文字本身的颜色，支持 #RRGGBB 和 #RRGGBBAA；color 则绘制文字下方的矩形填充。
alignleft / center / right，默认 left文字的水平对齐方式，多行时对每一行生效。
valigntop / middle / bottom，默认 middle整段文字在节点内的垂直对齐方式。
wraptrue / false，默认 falsefalse 为单行；true 按节点可用宽度自动换行。

单行状态文字

<text id="fps" position="16,12" size="220,32"
  font="default" font-size="18" text-color="#B6D8D3"
  align="left" valign="middle">FPS 60</text>

自动换行的说明文字

<text position="16,56" size="320,96"
  wrap="true" valign="top" font-size="16">显示当前页面状态和界面更新结果。文字会根据当前宽度自动换行。</text>

开启 wrap 后，中文可以逐字折行，英文优先按空格保留单词；单个单词超过整行宽度时再拆分。行高由字体度量决定，节点高度仍由 size 决定。多行超出高度时，按 valign 保留能放下的完整行：top 显示开头，middle 显示中间，bottom 显示末尾，适合持续追加的底部字幕。高度不足一行时仍按 Text 矩形裁切。

单行模式同样在自身矩形内显示。文本中的 &lt;、&amp; 等 XML 实体在显示前还原。Text 只能放文字内容。

13 / GoUI XML

image 标签

image 把图片资源绘制到自己的 Block 矩形中，使用通用布局属性。它自己的 color 填充色绘制在图片下方，radius 同时作用于填充区域和图片区域。

属性类型 / 默认值说明
src路径，必需资源路径，相对于启动时指定的 UI 目录，例如 assets/board.png。支持 PNG、JPEG 和 GIF；播放速度始终使用 GIF 本身的帧延迟。
fitstretch / contain / cover，默认 stretchstretch 拉伸填满，contain 保持比例完整显示，cover 保持比例铺满并裁剪。
playbackauto / segmented，默认 autoauto 使用 GIF 内的循环次数；segmented 从文件名读取进入、保持/循环与回正段，仅用于 GIF。
 
<image
  id="board-icon"
  anchor="0,0"
  pivot="0,0"
  position="16,16"
  size="48,48"
  src="assets/board.png"
  fit="contain" />

节点矩形由 size 决定。contain 将图片等比居中，留白处显示当前节点的填充色；cover 将图片等比居中并裁掉超出自身矩形的部分。radius 同时裁切图片和填充色。Image 可以包含 Text、Block 等子节点，先绘制图片再绘制子节点。子节点以 Image 的布局矩形为参考，不按 contain 留白区缩放；radius 不裁子树。

完整 GIF 播放与循环

默认 playback="auto"，按文件自带的循环次数播放。业务代码可调用 Play 从首帧重播已加载的 GIF，覆盖文件中的循环次数，不重新读取资源。

face, err := page.GetImage("face")
if err != nil { return err }
// 完整播放一次，完成后在窗口主循环中调用一次回调。
err = face.Play(false, func(*goui.Page) error {
    return face.SetSource("gif/normal.gif")
})
// 持续循环到下一次 Play、SetSource 或隐藏节点。
err = face.Play(true, nil)

Play(false, nil) 播放一次后保持末帧。循环时不可提供完成回调。Play 只接受可见的 auto GIF；静态图片和 segmented GIF 会报错。每次重播、换源或隐藏节点都会取消旧回调。完成回调内直接调用组件，不要再次 Dispatch；回调错误会从 Run 返回。隐藏后重新显示，按 XML 和 GIF 的默认规则从头播放。

按文件名分段播放

默认 playback="auto"，按 GIF 的帧延迟和循环次数自动播放；有限次播放结束后保持末帧。这种模式不解析文件名。设置 playback="segmented" 后，文件名尾部定义进入、保持/循环与回正段，帧速率保持不变。

<image id="face" src="gif/smile_[0.5s].gif"
  size="-1,-1" fit="contain" playback="segmented">
  <text id="answer" anchor="0,1" pivot="0,1" size="-1,100"
    margin="40,0,40,0" position="0,-20" font-size="28"
    align="center" valign="bottom" wrap="true" />
</image>
文件名尾部保持或循环规则请求回正后
_[0.5s]播放前 0.5 秒，停在该位置。从暂停位置继续到末尾。
_[0.5s,1.5s]0～0.5 秒进入，0.5～1.5 秒循环。结束当前轮后，播放 1.5 秒之后的回正段。
_[29]从第 0 帧播放到第 29 帧并保持。从保持处继续。
_[29,50]29 之前进入，29～50 帧循环，包含第 50 帧。结束当前轮后，播放第 50 帧之后的回正段。

第二个参数是结束位置，不是时长。秒数可以是小数，不需要对齐帧边界；帧索引从 0 开始，按每帧真实延迟换算。支持逗号周围空格和 2.0 s 写法，但一组参数不能混用秒和帧。位置不能越过 GIF 末尾；单个保持点允许正好等于总时长，此时停在末帧。错误会在加载时报告 XML 文件与行列位置。

完成当前动作后切换

对当前可见的 GIF 调用 Finish，请求完成当前这一轮。普通 GIF 保留当前进度，播到末尾后通知，不会重新播放开头；分段 GIF 继续按进入、循环和回正规则完成。回调在窗口主循环中执行一次，可以直接操作组件；返回的错误会结束 Run。

face, err := page.GetImage("face")
if err != nil { return err }
return face.Finish(func(*goui.Page) error {
    return face.SetSource("gif/laugh_[0.5s, 1.0s].gif")
})

Finish 必须提供完成回调，同次播放只允许请求一次；静态图片和隐藏节点不能调用。回调内直接使用组件，不要再次调用 Dispatch。隐藏图片或父 Block 会取消待完成回调并释放画布，重新显示从首帧开始；已经可见时再次 SetVisible(true) 不会重播。需要立即切换可直接调用 SetSource。

通过 Go 修改图片路径

Image.SetSource("assets/next.png") 按需加载 UI 目录中的新资源，沿用 Image 的 fit、playback、布局和样式。成功后替换当前图片，从首帧播放；失败保留旧图。同一路径也会重新加载。图片子节点和已有文字保持不变。

一个 Image 就可以轮换不同表情，无需为每张 GIF 建节点。只有初始 src 和实际换源的目标会被解码，不预加载整个候选表，也不缓存所有 GIF；替换后释放对旧素材、播放画布和旧完成回调的引用。segmented 模式换入的仍须是带合法参数的 GIF；普通图片互换使用 auto。

err := app.Dispatch(ctx, func(page *goui.Page) error {
    face, err := page.GetImage("face")
    if err != nil { return err }
    return face.SetSource("gif/laugh_[0.5s, 1.0s].gif")
})

两种模式都复用窗口帧循环，不增加 goroutine 或独立定时器；仅帧变化时更新图片脏区。GIF 的透明色、局部帧处置、Image 缩放、圆角与 Block 动画仍然有效。

机器人示例

可运行项目位于 example/robot-face/。设备只用一个 Image 显示黑底 GIF，内部一个底部 Text 显示全部文字；文字背景透明，内容为空时隐藏。访问 http://localhost:8080/ 使用调试面板，直接点击表情名称，并设置“持续循环”和“立即打断”。

GET /api/expressions 返回全部可用名称及中文显示名；POST /api/emotion 按名称播放。name 必填，loop 默认 false，interrupt 默认 true：

{"name":"music","loop":true,"interrupt":false}

此请求等当前 GIF 播完本轮后，再持续循环音乐。interrupt=true 会立即打断；等待期间只保留最新请求，不排队。同一动作再次请求也按所选策略重播。响应中的 expression 是实际表情，loop 表示是否持续循环，pending（可选）是待切换请求；新请求立即打断时清除 pending。

动作默认完整播放一次后回 normal。正常 GIF 播完一次眨眼后保持睁眼，随机等待 2～5 秒重播；正常表情忽略 loop。示例使用 auto 模式和 Play，不读取文件名中的暂停点。随机等待、表情名称与 Gin 接口均属于机器人项目，框架只提供通用组件和播放能力。

POST /api/display 的 text 替换所有文字、append 追加模型增量，空 text 清空显示。例如 {"text":"正在倾听…"}；开始回答时先用第一段替换提示，再追加后续片段。HTTP 与眨眼等待任务通过 app.Dispatch 提交。浏览器通过 Application.Snapshot 获取设备已绘制的帧，动作、随机眨眼和字幕与 UI 共用结果，存在少量采样和网络延迟。

属性类型 / 默认值说明

<button id="start-button" position="24,300" size="180,48"
  color="#B4473B" hover-color="#D05A4D" radius="6">

button, err := page.GetButton("start-button")

鼠标事件

Button 可分别注册 OnMouseEnter、OnMouseLeave、OnMouseDown、OnMouseUp 和 OnClick。每种事件在同一按钮上只能注册一次；每个回调都接收当前 *goui.Page 并返回 error。

button, err := page.GetButton("start-button")
if err != nil { return err }

if err := button.OnMouseEnter(func(*goui.Page) error {
  return status.SetText("鼠标进入按钮")
}); err != nil { return err }
if err := button.OnMouseLeave(func(*goui.Page) error {
  return status.SetText("鼠标离开按钮")
}); err != nil { return err }
return button.OnClick(func(*goui.Page) error {
  return status.SetText("命令已执行")
})

hover-color 只负责按钮底色的悬停反馈，不需要再用 OnMouseEnter 和 OnMouseLeave 手动切换颜色；这两个 Go 事件可继续用于更新提示或业务状态。

OnMouseEnter 和 OnMouseLeave 在鼠标目标变化时触发；OnMouseDown 在左键于按钮上按下时触发；OnMouseUp 在左键释放且指针位于按钮上时触发。OnClick 只在按下和释放命中同一个按钮时触发。

点击与重叠规则

  1. 从绘制顺序的最上层向下，只检查可见的 Button。点击位置内的第一个按钮就是此次目标；Block、Text、Image 即使完全盖住它，也不会挡住命中。
  2. Button 的完整矩形参与命中，包括圆角外的矩形边角。普通文字或图标覆盖按钮时，仍可点击按钮。
  3. 按下时记录目标；释放时按当前位置重新查找最上层按钮。释放在另一个按钮上或按钮外时，不触发原按钮的 Click；MouseUp 则发给释放位置上的可用按钮。按压期间隐藏按钮、隐藏其父节点或禁用按钮，会取消该次按压和悬停；即使随后恢复，也需要重新按下。这条规则同样适用于 MouseUp 回调中的状态修改。
  4. 最上层按钮禁用时，它不接收事件且会挡住下层按钮。设为 visible="false" 的节点及子树不参与命中。
  5. 位移动画的绘制和命中共用取整后的矩形；父节点旋转或缩放后，按钮命中使用同一个屏幕变换，命中区域仍是变换后的矩形。

子节点与绘制层级

Block 和 Button 可以包含子节点，提供坐标空间和绘制层级。父子关系用于组合界面，子节点可以绘制到父矩形外。

  • 子节点的 anchor 参考父节点矩形，pivot 参考自身矩形；对齐后再应用像素偏移。
  • 先绘制节点自身，再按 XML 顺序绘制其子树。同一父级中，后出现的子树位于上层。
  • 父矩形及圆角不裁剪子树；子节点越出父矩形的部分仍可绘制，越出的按钮仍可参与命中。最终绘制受渲染目标边界限制。
  • Text 的文字、Image 的图片各自在自身绘制区域内处理溢出；visible="false" 则隐藏整个子树。
  • 按钮命中使用与绘制相反的顺序，只检查 Button，普通可视节点不拦截按钮。
<block id="card" position="24,96" size="420,180"
  color="#17212B" radius="12">
  <text position="16,16" size="388,32" font-size="20">Display 0</text>
  <text position="16,60" size="388,28"
    text-color="#B6D8D3">desktop window / 960x640</text>
</block>

第二个 Text 的 position="16,60" 相对父卡片计算。移动卡片时，其子树一起移动；子节点数量不会改变父节点尺寸。

18 / Go API

Block 动画方法

动画由 Go 代码启动，不在 XML 中另加动画标签或属性。每个方法填写目标值和持续时间，使用线性插值；持续时间为 0 时立即生效，负数会返回错误。

方法目标值说明
MoveTo(x, y, duration)父节点坐标中的 position从当前位置移动到目标偏移；目标坐标为整数像素。
RotateTo(degrees, duration)角度绕当前节点的 pivot 顺时针旋转；屏幕坐标中正角度向右转。
ScaleTo(x, y, duration)X、Y 缩放倍数绕 pivot 缩放；1 表示原始大小，数值必须大于 0。

参数中的 duration 使用 Go 的 time.Duration，例如 300*time.Millisecond 或 time.Second。再次调用同一方法会从当前动画位置继续；移动、旋转和缩放可以同时进行。父节点的旋转和缩放会作用于整个子树。按钮事件回调返回的错误会传回窗口循环并结束 Run。

import "time"

target, err := page.GetBlock("motion-target")
if err != nil { return err }

duration := 500 * time.Millisecond
if err := target.MoveTo(120, 40, duration); err != nil { return err }
if err := target.RotateTo(90, duration); err != nil { return err }
return target.ScaleTo(1.5, 1.5, duration)

动画期间渲染器逐帧更新位置和变换，结束后继续使用静态帧缓存。旋转和缩放后的按钮仍按屏幕上的实际变换区域命中；命中区域本身仍是按钮矩形，不会被 radius 裁成圆角。

小数坐标与像素取整

XML 中的像素位置、固定尺寸和边距填写整数，但锚点乘上父尺寸时，布局中间结果可能带小数。这是几何坐标，最后需要对应到实际像素网格。

为什么会算出 280.5

父节点左边缘为 0，宽 801 像素；子节点宽 240 像素，anchor 和 pivot 的 X 分量均为 0.5，横向偏移为 0：

父节点中心 = 801 × 0.5 = 400.5 自身左边缘 = 400.5 − 240 × 0.5 = 280.5 自身右边缘 = 280.5 + 240 = 520.5

布局使用小数完成整棵树的坐标计算，最终将屏幕坐标中的左、上、右、下边缘各自取最近整数；恰好半像素时向远离 0 的方向取整。上例得到左边缘 281、右边缘 521，宽度仍为 240。

绘制和按钮命中共用这个最终矩形。相邻节点共享同一条几何边缘时，取整结果也相同。anchor、pivot 仍可填写 0～1 之间的小数。

Block 与局部脏区重绘

所有可视节点共享 Block 的矩形和层级，因此状态变化可以标记对应节点需要重绘。XML 不需要增加脏标记标签或属性。Go API 可更新文字、颜色和可见状态，也可以启动位置、旋转和缩放动画。

status, err := page.GetText("status")
if err != nil { return err }
if err := status.SetText("Display connected"); err != nil { return err }

panel, err := page.GetBlock("status-panel")
if err != nil { return err }
if err := panel.SetColor(color.NRGBA{R: 32, G: 46, B: 46, A: 255}); err != nil { return err }

button, err := page.GetButton("start-button")
if err != nil { return err }
return button.SetDisabled(true)

静态状态更新会使相关矩形进入脏区。下一次请求帧时，渲染器重画脏区内的背景和相交节点，未改变的部分沿用上一帧。动画运行时会重绘当前帧；移动动画重新计算布局，旋转和缩放会重绘受变换影响的画面。调整窗口尺寸时会重新计算整棵树。查找使用展开后的 ID，例如 left.status.value。

从网络或设备回调更新页面

组件修改和绘制在窗口主循环中串行进行。初始化与按钮回调可以直接操作组件；HTTP 或设备的外部 goroutine 使用 app.Dispatch(ctx, callback)，将一组修改交给主循环执行，并等待执行结果。

err := app.Dispatch(ctx, func(page *goui.Page) error {
  status, err := page.GetText("status")
  if err != nil { return err }
  return status.SetText("收到设备状态")
})

Dispatch 的回调保持简短，不在其中等待网络或再次调用 Dispatch。回调错误返回提交方；未启动、已关闭或 context 已取消时也返回错误。尚未执行就已经取消的任务会被跳过。

变化范围。隐藏或显示分组时，脏区覆盖节点及子树的范围；子节点可以超出父矩形，因此这些越界区域也会被重画。当前更新接口不修改节点位置和尺寸。

字体文件怎么选

你下载的阿里巴巴普惠体 3.0 按字重分目录，每个目录中又提供多种格式。同一个字重使用一种合适的字体文件即可；本教程的字体注册使用 TTF。

同一个字重为什么有五种文件

扩展名用途本项目中的选择
.ttf常用字体文件，通常使用 TrueType 轮廓。用于配置中的 font.src。
.otf常见的 OpenType 字体文件，可能使用不同的字形轮廓格式。这套字体同时提供的另一种格式；具体支持取决于字体解析器。
.woff / .woff2面向网页传输的字体格式，通过压缩减小下载体积。网页嵌入字体时使用。
.eot较早的网页嵌入字体格式，源于旧版 Internet Explorer 的使用场景。此处选择随包提供的 TTF。

字重名称是什么意思

35 Thin 是细字重，之后依次有 45 Light、55 Regular、65 Medium、75 SemiBold、85 Bold、95 ExtraBold、105 Heavy 和 115 Black。目录数字是这套字体的字重命名，font-size 则控制显示大小，两者分别设置。

Regular 与 RegularL3

这两份本地 TTF 的字重值均为 400，属于常规字重。L3 表示更大的字符覆盖版本：本地普通 Regular 的字符映射约覆盖 2.9 万个 Unicode 码位，RegularL3 约覆盖 6 万个。L3 增加的是字符覆盖。

本地字体文件文件大小用法
55-Regular.ttf8,532,824 字节，约 8.5 MB本教程默认字体示例。
55-RegularL3.ttf21,725,156 字节，约 21.7 MB需要更广字符覆盖时，可改为注册这份文件。

先在 UI 目录中提供 AlibabaPuHuiTi-3-55-Regular.ttf 并注册为 default；需要粗体时再提供相应字重，按独立名称注册。随应用分发时应同时保留字体包的授权说明；当前下载目录中未发现单独的授权文件，可从官方字体包补齐。

格式说明参考：OpenType 文件规范、WOFF 2.0 规范、EOT 格式说明。字重、码位覆盖与文件大小依据当前下载的字体文件核对。

标签速查

标签用途常用属性 / 内容子节点
<ui>页面根节点，覆盖渲染目标。id、color是
<block>基础矩形、填充色、坐标空间和分组。布局属性、通用属性；Go API 可移动、旋转、缩放是
<text>显示单行或自动换行文字。布局与通用属性、font、font-size、text-color、align、valign、wrap文字内容
<image>绘制静态图片或播放 GIF 动画。布局与通用属性、src、fit、playback；Go API 可 SetSource、Play、Finish是
<button>可命中的交互区域，可组合子节点。布局与通用属性、disabled、hover-color；鼠标事件由 Go 代码绑定是
<component>展开组件文件并给 ID 加点号前缀。引用：src、name；定义：透明根包装定义中可有多个节点；引用为空标签

字体配置标签速查

标签用途写法
<config>config.xml 根节点。可包含 app、window，并必须包含 fonts。
<app>应用名和元数据版本。name、version；最多一个。
<window>桌面显示设置和后端选择。backend、display、width、height、fullscreen。
<fonts>字体注册表。包含多个 font，必须登记 default。
<font>为 TTF 文件注册名称。name、src 均必需。

布局属性速查

属性格式记忆方式
anchor"x,y"，0～1父组件上的点。
pivot"x,y"，0～1当前组件自身的点。
position"x,y"，整数像素两个点对齐后再偏移。
size"width,height"，整数像素-1 表示这一轴填充父组件。
margin"left,top,right,bottom"，非负整数像素仅影响 size=-1 的轴；其他两个方向的值忽略。
