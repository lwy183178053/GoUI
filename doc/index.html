GoUI / XML UI Guide

GoUI XML 标签使用教程

用 Block 描述界面，用 anchor、pivot、position 和 size 布局；当 size 使用 -1 时，再用 margin 控制边距。Text、Image、Button 共享 Block 的基础属性，只增加各自必需的能力。

标签规范 0.1纯 GoDRM/KMSBlock 布局
01 / GoUI XML

开始使用

先准备一个 UI 目录，在 config.xml 中登记字体，在 main.xml 中描述界面。预览版支持 block、text、image、button 和透明展开的 component；布局、XML 解析和软件绘制都由平台无关的 Go 代码完成。

定位一个节点

anchor 选父级上的点，pivot 选自身上的点；两点对齐后，再由 position 偏移，并用 size 定尺寸。

组合与复用

文字和图标都写成独立节点，放进普通 Block 或 Button。需要复用一组节点时，把内容放到组件 XML，再用 component 引用。

最小 config.xml

<config>
  <fonts>
    <font name="default" src="fonts/AlibabaPuHuiTi-3-55-Regular.ttf" />
  </fonts>
</config>

将对应的 TTF 文件放入 UI 目录的 fonts/ 中。这里的 default 是注册名称，后面的 Text 省略 font 时就使用它。

最小 main.xml

<ui color="#0D1117">
  <text
    id="title"
    anchor="0.5,0"
    pivot="0.5,0"
    position="0,24"
    size="320,40"
    text-color="#F4F7F7"
    font-size="24">GoUI</text>
</ui>

坐标使用渲染目标的像素，父节点左上角为原点，X 向右、Y 向下。根 ui 的矩形就是当前 DRM/KMS 输出区域。

02 / GoUI XML

UI 目录与文件加载

启动时指定 UI 目录，加载器自动读取其中的 config.xml 和 main.xml。其它 XML 按组件引用加载，资源可以按用途分目录存放。

ui/
  main.xml
  config.xml
  components/
    display-card.xml
    parts/
      connection.xml
  fonts/
    AlibabaPuHuiTi-3-55-Regular.ttf
    AlibabaPuHuiTi-3-75-SemiBold.ttf
  assets/
    board.png
  • config.xml 和 main.xml 都是必需文件；前者以 <config> 为根，后者以 <ui> 为根。
  • 先读取配置并注册字体，再读取主界面、展开组件并检查最终节点树。没有被引用的组件文件不加载。
  • 路径使用正斜杠，可使用 ../ 访问上级目录，但解析后的路径必须留在指定的 UI 目录内。
路径属性相对基准示例
component.src写下该引用的 XML 文件所在目录components/display-card.xml 中的 parts/connection.xml 指向 components/parts/connection.xml。
image.srcUI 目录任何组件中的 assets/board.png 都指向 ui/assets/board.png。
config 中 font.srcUI 目录fonts/AlibabaPuHuiTi-3-55-Regular.ttf 指向 ui/fonts/AlibabaPuHuiTi-3-55-Regular.ttf。
出错时停止加载。缺少必需文件、XML 格式错误、未知标签或属性、重复名称或 ID、无效字体引用都属于加载错误。错误应指出来源文件和位置；组件错误还应显示引用关系。
03 / GoUI XML

config、fonts 与 font

字体统一在 config.xml 中登记。fonts 保存字体列表，每个 font 把一个名称映射到 UI 目录中的 TTF 文件；Text 按名称选择字体。

<config>
  <fonts>
    <font name="default"
      src="fonts/AlibabaPuHuiTi-3-55-Regular.ttf" />
    <font name="semibold"
      src="fonts/AlibabaPuHuiTi-3-75-SemiBold.ttf" />
  </fonts>
</config>
标签 / 属性写法说明
config配置文件根标签整个 UI 目录使用这份配置。
fonts包含多个 font字体注册表，至少登记一个名为 default 的字体。
font.name非空字符串，必需供 text font="名称" 引用；同一注册表中的名称不能重复。
font.srcTTF 文件路径，必需相对于 UI 目录，字体随应用资源提供。

上例中，正文省略 font 即使用 Regular；需要较粗的标题时，显式选择 semibold。需要几种字重，就登记对应的几个文件。

<text size="320,40" font="semibold" font-size="24">显示设备</text>

缺少 default、字体重名、文件不存在或无法解析，以及 Text 引用未注册字体时，加载失败。字体直接从 UI 目录读取，目标 Linux 的系统字体不参与查找。

04 / GoUI XML

通用属性

这些属性由 Block 提供，block、text、image 和 button 都可以使用。每个节点有自己的属性值；visible 控制整棵子树的显示，坐标和尺寸则为子节点提供布局参考。

id

类型：非空字符串 · 默认：无可选节点名称，用于代码查找、状态更新和调试。组件中的 id 在展开后加上组件名前缀，例如 left.title；最终节点树中的 ID 必须全局唯一，重复时报错。根 ui 也可以设置 ID。

visible

类型：true / false · 默认：true设为 false 后，当前节点及整个子树都不绘制，其中的按钮也不参与命中测试。

color

类型：颜色 · 默认：透明设置当前节点自己的矩形填充色，支持 #RRGGBB 和 #RRGGBBAA。所有可视标签都可以使用这个属性，值只作用于当前节点；子节点使用自己的颜色值。Text 的文字颜色由 text-color 设置。根 ui 的 color 是清屏背景色，默认黑色。

radius

类型：非负像素数 · 默认：0设置当前节点填充区域和图片区域的圆角。超过短边一半时按短边一半绘制。圆角只作用于当前节点，子节点可绘制到父矩形外；按钮仍按完整矩形命中。

05 / GoUI XML

anchor

anchor="x,y" 选择父节点矩形中的一个点。两个值都在 0～1 之间，默认 0,0；它决定自身的 pivot 要对齐父节点的什么位置。

anchor="0,0"父节点左上角。
anchor="0.5,0.5"父节点中心。
anchor="1,0"父节点右上角。
anchor="1,1"父节点右下角。

父节点尺寸变化时，这个参考点随之移动。当前轴的 size 为 -1 时，改由该轴边距决定填充位置。

06 / GoUI XML

pivot

pivot="x,y" 选择当前节点自身矩形中的一个点，两个值都在 0～1 之间，默认 0,0。它与父节点上的 anchor 对齐后，再加上 position 偏移。

pivot="0,0" 使用自身左上角，pivot="0.5,0.5" 使用自身中心，pivot="1,1" 使用自身右下角。锚点和轴心只决定对齐方式，尺寸由 size 决定。

把自身中心对齐到父节点中心

<block size="800,400">
  <block anchor="0.5,0.5" pivot="0.5,0.5"
    position="0,0" size="240,80" color="#17212B" />
</block>
parentAnchor = parentRect.origin + parentRect.size × anchor selfOrigin = parentAnchor + position − selfRect.size × pivot

这里的乘法按 X、Y 分别计算。计算结果可以带小数，最终如何对应实际像素见“小数坐标与像素取整”。

07 / GoUI XML

position

position="x,y" 是父级 anchor 与自身 pivot 对齐后的整数像素偏移，默认 0,0。正值向右、向下移动，负值向左、向上移动。

给状态卡片留出偏移

<block
  id="status-card"
  anchor="0,0"
  pivot="0,0"
  position="24,96"
  size="420,180"
  color="#17212B"
  radius="12" />

这里的 position="24,96" 表示卡片左上角距离父组件左上角 24、96 像素。若把 pivot 改成 0.5,0.5，同一个偏移就会作用在卡片中心。

08 / GoUI XML

size

size="width,height" 必须填写两个整数像素值。非负整数表示固定尺寸，-1 表示该方向填充父节点；宽、高分别独立判断，小于 -1 的值无效。

写法结果适用场景
size="240,80"宽 240，高 80固定按钮、标题、图标区域。
size="-1,48"宽填充，高 48横向顶栏、状态条。
size="320,-1"宽 320，高填充侧栏、纵向面板。
size="-1,-1"宽高都填充内容根 Block 或全尺寸背景。

只填充一个方向

<block
  anchor="0,0"
  pivot="0,0"
  position="0,18"
  size="-1,48"
  margin="24,80,24,80"
  color="#23303A" />

这里宽度为 -1，所以只使用左、右边距 24；上、下边距 80 被忽略。高度固定为 48，其 Y 位置仍由 anchor、pivot 和 position 决定。

09 / GoUI XML

margin 边距

margin 按 left,top,right,bottom 的顺序填写四个非负整数像素值，默认是 0,0,0,0。它只作用于 size 中值为 -1 的方向。

size生效的 margin 值忽略的 margin 值
"-1,48"left、righttop、bottom
"320,-1"top、bottomleft、right
"-1,-1"left、top、right、bottom无
"320,48"无left、top、right、bottom

填充方向由 margin 决定，该方向的 anchor、pivot、position 不生效；固定尺寸方向仍按这三个属性定位。左右或上下边距总和超过父尺寸时，该方向尺寸按 0 处理。

10 / GoUI XML

ui 根标签

ui 是 main.xml 的唯一根节点。它的矩形自动覆盖当前渲染目标，直接子节点以这块区域作为父级坐标空间。

属性类型 / 默认值说明
color颜色，默认 #000000渲染背景和清屏颜色，支持 #RRGGBB、#RRGGBBAA。
id非空字符串，可选给根节点命名，最终 ID 全局唯一。
 
<ui id="drm-monitor" color="#0D1117">
  <block size="-1,-1" margin="24,24,24,24" />
</ui>

ui 的尺寸来自渲染目标，子节点用锚点或填充规则适配尺寸变化。字体等运行配置统一放在 config.xml 中。

11 / GoUI XML

block 标签

block 是最基础的可视节点，也是所有控件的共同基础。它可以有填充色、子节点和自己的布局矩形，但不会自动排列子节点。控件复用 Block 已有的布局、颜色和圆角属性，只增加自身需要的功能。

最小写法

<block
  id="panel"
  anchor="0.5,0.5"
  pivot="0.5,0.5"
  position="0,0"
  size="480,260"
  color="#17212B"
  radius="12" />
idvisibleanchorpivotpositionsizemargincolorradius
布局属性默认 / 要求说明
anchor0,0省略时使用父组件左上角。
pivot0,0省略时使用当前 Block 左上角。
position0,0省略时两个参考点重合。
size必需每个可视子节点都必须给出宽高；只有 ui 根节点自动占满渲染目标。
margin0,0,0,0顺序为左、上、右、下；宽为 -1 时只读左右，高为 -1 时只读上下。

Block 的子节点坐标相对于该 Block 的左上角。父 Block 只负责提供坐标空间和绘制顺序，不会因为子节点数量改变自己的大小。

不要把 block 当成自动布局容器。如果两个子节点要上下排列，就直接给它们不同的 position；如果要横向排列，也直接写各自的 X 偏移。
12 / GoUI XML

text 标签

text 用节点内容显示文字，共享 Block 的布局、填充色和圆角属性，并提供字体、文字颜色、对齐和自动换行。

属性类型 / 默认值说明
font已注册字体名，默认 default引用 config.xml 中的 font.name，例如 semibold。
font-size像素，默认 16文字大小。
text-color颜色，默认 #F4F7F7文字本身的颜色，支持 #RRGGBB 和 #RRGGBBAA；color 则绘制文字下方的矩形填充。
alignleft / center / right，默认 left文字的水平对齐方式，多行时对每一行生效。
valigntop / middle / bottom，默认 middle整段文字在节点内的垂直对齐方式。
wraptrue / false，默认 falsefalse 为单行；true 按节点可用宽度自动换行。

单行状态文字

<text id="fps" position="16,12" size="220,32"
  font="default" font-size="18" text-color="#B6D8D3"
  align="left" valign="middle">FPS 60</text>

自动换行的说明文字

<text position="16,56" size="320,96"
  wrap="true" valign="top" font-size="16">显示连接状态、当前分辨率和 DRM page flip 的测试结果。文字会根据当前宽度自动换行。</text>

开启 wrap 后，中文可以逐字折行，英文优先按空格保留单词；单个单词超过整行宽度时再拆分。行高由字体度量决定，超出当前 Text 矩形的文字裁掉，节点高度仍由 size 决定。

单行模式同样在自身矩形内显示。文本中的 &lt;、&amp; 等 XML 实体在显示前还原。Text 只能放文字内容。

13 / GoUI XML

image 标签

image 把图片资源绘制到自己的 Block 矩形中，使用通用布局属性。它自己的 color 填充色绘制在图片下方，radius 同时作用于填充区域和图片区域。

属性类型 / 默认值说明
src路径，必需资源路径，相对于启动时指定的 UI 目录，例如 assets/board.png。预览版可读取 PNG、JPEG 和 GIF 静态帧。
fitstretch / contain / cover，默认 stretchstretch 拉伸填满，contain 保持比例完整显示，cover 保持比例铺满并裁剪。
 
<image
  id="board-icon"
  anchor="0,0"
  pivot="0,0"
  position="16,16"
  size="48,48"
  src="assets/board.png"
  fit="contain" />

节点矩形由 size 决定。contain 将图片等比居中，留白处显示当前节点的填充色；cover 将图片等比居中并裁掉超出自身矩形的部分。radius 同时裁切图片和填充色。Image 不包含子节点。

14 / GoUI XML

button 标签

button 是接收点击的 Block，只增加点击命令和禁用状态。布局、颜色和圆角使用通用属性，文字与图片写成它的子节点。

属性类型 / 默认值说明
on-click命令名，可选点击成功后执行已注册的命令，例如 drm.start。
disabledtrue / false，默认 false为 true 时不执行点击命令，但仍挡住下方的按钮；外观由自身属性与子节点决定。
 
<button id="start-button" position="24,300" size="180,48"
  color="#B4473B" radius="6" on-click="drm.start">
  <text size="-1,-1" text-color="#FFFFFF" font-size="16"
    align="center" valign="middle">Start DRM</text>
</button>

只有 button 可以声明 on-click；写在 block、text、image 等其它标签上属于加载错误。命令名由 Go 代码注册，XML 中填写名称。预览窗口把鼠标左键按下和释放转换成按钮命中事件。

err := renderer.RegisterAction("drm.start", func() error {
  // 在这里调用应用自己的 Go 逻辑，也可以更新有 ID 的 UI 节点。
  return renderer.SetText("status", "命令已执行")
})

点击与重叠规则

  1. 从绘制顺序的最上层向下，只检查可见的 Button。点击位置内的第一个按钮就是此次目标；Block、Text、Image 即使完全盖住它，也不会挡住命中。
  2. Button 的完整矩形参与命中，包括圆角外的矩形边角。普通文字或图标覆盖按钮时，仍可点击按钮。
  3. 按下时记录目标；释放时重新查找当前位置最上层的按钮。两次是同一个按钮且按钮可用时，才执行一次 on-click。移出后释放、隐藏或禁用按钮都会取消本次点击。
  4. 最上层按钮禁用时，本次点击被挡住，下层按钮也不执行。设为 visible="false" 的节点及子树不参与命中。
15 / GoUI XML

component 标签

一个组件使用一个 XML 文件，文件最外层用 <component> 包住内容。在界面中用同名标签填写 src 和 name 引用它。加载时将引用替换为文件内的内容，并为其中的 ID 加上组件名前缀。

引用属性要求说明
srcXML 路径，必需相对于当前 XML 文件所在目录解析。
name非空实例名，必需作为 ID 前缀；名称不能含点号，展开后的完整组件名必须全局唯一。

同一个文件引用两次：main.xml

<ui color="#0D1117">
  <block position="24,80" size="440,196">
    <component src="components/display-card.xml" name="left" />
  </block>
  <block position="488,80" size="440,196">
    <component src="components/display-card.xml" name="right" />
  </block>
</ui>

组件文件：components/display-card.xml

<component>
  <block id="panel" size="-1,-1" color="#17212B" radius="12">
    <text id="title" position="20,18" size="400,32"
      font-size="20">Display</text>
    <component src="parts/connection.xml" name="connection" />
  </block>
</component>

嵌套组件：components/parts/connection.xml

<component>
  <text id="state" position="20,62" size="400,28"
    text-color="#B6D8D3">Connected</text>
  <text id="detail" position="20,100" size="400,28"
    text-color="#A8B3B5">HDMI-A-1 / 1920 × 1080</text>
</component>

组件文件的根 <component> 是透明包装，可以放多个子标签；上面的嵌套组件就直接提供两个 Text。引用处的 <component src="…" name="…" /> 和文件外层包装都会移除，子节点直接插入引用位置，保留原来的顺序。

组件引用使用 src、name 两个属性，以空标签书写。src 相对于当前 XML 文件解析，且不能越出 UI 目录。组件文件只定义这一份组件；需要嵌套时继续引用其它文件。循环引用会报错。

名字与 ID 怎么展开

源文件中的名称left 实例right 实例
外层组件名leftright
id="panel"left.panelright.panel
id="title"left.titleright.title
嵌套 name="connection"left.connectionright.connection
嵌套 id="state"left.connection.stateright.connection.state

前缀覆盖组件展开后的整个子树。普通父 Block 的 ID 不参与拼接，因此上例的标题是 left.title。已有 ID 按“组件名 + 点号 + 原 ID”生成，没有 ID 的节点保持无 ID。名称按最终字符串检查唯一性；重复组件名或最终 ID 都是加载错误。代码通过 left.connection.state 这样的完整 ID 查找节点。

一组内容的位置与大小

组件本身只负责展开和命名。调用处用已有的 Block 提供位置和尺寸，上例的卡片内容便以两个包装 Block 分别作为父级。组件内部的填充尺寸与锚点随父矩形重新计算，固定尺寸仍按各自的像素值布局。

16 / GoUI XML

子节点与绘制层级

Block 和 Button 可以包含子节点，提供坐标空间和绘制层级。父子关系用于组合界面，子节点可以绘制到父矩形外。

  • 子节点的 anchor 参考父节点矩形，pivot 参考自身矩形；对齐后再应用像素偏移。
  • 先绘制节点自身，再按 XML 顺序绘制其子树。同一父级中，后出现的子树位于上层。
  • 父矩形及圆角不裁剪子树；子节点越出父矩形的部分仍可绘制，越出的按钮仍可参与命中。最终绘制受渲染目标边界限制。
  • Text 的文字、Image 的图片各自在自身绘制区域内处理溢出；visible="false" 则隐藏整个子树。
  • 按钮命中使用与绘制相反的顺序，只检查 Button，普通可视节点不拦截按钮。
<block id="card" position="24,96" size="420,180"
  color="#17212B" radius="12">
  <text position="16,16" size="388,32" font-size="20">Display 0</text>
  <text position="16,60" size="388,28"
    text-color="#B6D8D3">connected / 1920x1080</text>
</block>

第二个 Text 的 position="16,60" 相对父卡片计算。移动卡片时，其子树一起移动；子节点数量不会改变父节点尺寸。

小数坐标与像素取整

XML 中的像素位置、固定尺寸和边距填写整数，但锚点乘上父尺寸时，布局中间结果可能带小数。这是几何坐标，最后需要对应到实际像素网格。

为什么会算出 280.5

父节点左边缘为 0，宽 801 像素；子节点宽 240 像素，anchor 和 pivot 的 X 分量均为 0.5，横向偏移为 0：

父节点中心 = 801 × 0.5 = 400.5 自身左边缘 = 400.5 − 240 × 0.5 = 280.5 自身右边缘 = 280.5 + 240 = 520.5

布局使用小数完成整棵树的坐标计算，最终将屏幕坐标中的左、上、右、下边缘各自取最近整数；恰好半像素时向远离 0 的方向取整。上例得到左边缘 281、右边缘 521，宽度仍为 240。

绘制和按钮命中共用这个最终矩形。相邻节点共享同一条几何边缘时，取整结果也相同。anchor、pivot 仍可填写 0～1 之间的小数。

18 / GoUI XML

Block 与局部脏区重绘

所有可视节点共享 Block 的矩形和层级，因此状态变化可以标记对应节点需要重绘。XML 不需要增加脏标记标签或属性。预览版提供按 ID 更新文字、颜色、可见状态和按钮禁用状态的接口。

renderer.SetText("status", "DRM connected")
renderer.SetColor("status-panel", color.NRGBA{R: 32, G: 46, B: 46, A: 255})
renderer.SetVisible("warning", false)
renderer.SetDisabled("start-button", true)

这些更新会使相关矩形进入脏区。下一次请求帧时，渲染器清理并重画脏区内的背景和相交节点，返回新帧给窗口后端；未改变的部分沿用上一帧。调整窗口尺寸时会重新计算整棵树并完整绘制。查找使用展开后的 ID，例如 left.status.value。

变化范围。隐藏或显示分组时，脏区覆盖节点及子树的范围；子节点可以超出父矩形，因此这些越界区域也会被重画。当前更新接口不修改节点位置和尺寸。
19 / GoUI XML

字体文件怎么选

你下载的阿里巴巴普惠体 3.0 按字重分目录，每个目录中又提供多种格式。同一个字重使用一种合适的字体文件即可；本教程的字体注册使用 TTF。

同一个字重为什么有五种文件

扩展名用途本项目中的选择
.ttf常用字体文件，通常使用 TrueType 轮廓。用于配置中的 font.src。
.otf常见的 OpenType 字体文件，可能使用不同的字形轮廓格式。这套字体同时提供的另一种格式；具体支持取决于字体解析器。
.woff / .woff2面向网页传输的字体格式，通过压缩减小下载体积。网页嵌入字体时使用。
.eot较早的网页嵌入字体格式，源于旧版 Internet Explorer 的使用场景。此处选择随包提供的 TTF。

字重名称是什么意思

35 Thin 是细字重，之后依次有 45 Light、55 Regular、65 Medium、75 SemiBold、85 Bold、95 ExtraBold、105 Heavy 和 115 Black。目录数字是这套字体的字重命名，font-size 则控制显示大小，两者分别设置。

Regular 与 RegularL3

这两份本地 TTF 的字重值均为 400，属于常规字重。L3 表示更大的字符覆盖版本：本地普通 Regular 的字符映射约覆盖 2.9 万个 Unicode 码位，RegularL3 约覆盖 6 万个。L3 增加的是字符覆盖。

本地字体文件文件大小用法
55-Regular.ttf8,532,824 字节，约 8.5 MB本教程默认字体示例。
55-RegularL3.ttf21,725,156 字节，约 21.7 MB需要更广字符覆盖时，可改为注册这份文件。

先在 UI 目录中提供 AlibabaPuHuiTi-3-55-Regular.ttf 并注册为 default；需要粗体时再提供相应字重，按独立名称注册。随应用分发时应同时保留字体包的授权说明；当前下载目录中未发现单独的授权文件，可从官方字体包补齐。

格式说明参考：OpenType 文件规范、WOFF 2.0 规范、EOT 格式说明。字重、码位覆盖与文件大小依据当前下载的字体文件核对。

标签用途常用属性 / 内容子节点

布局属性速查

属性格式记忆方式
anchor"x,y"，0～1父组件上的点。
pivot"x,y"，0～1当前组件自身的点。
position"x,y"，整数像素两个点对齐后再偏移。
size"width,height"，整数像素-1 表示这一轴填充父组件。
margin"left,top,right,bottom"，非负整数像素仅影响 size=-1 的轴；其他两个方向的值忽略。
